# 🎬 CineVerse

CineVerse is a modern movie discovery web application built with **React**, **Vite**, **Tailwind CSS**, and the **TMDB API**. It allows users to explore trending, top-rated, popular, upcoming, and now-playing movies, search for their favorite titles in real time, and watch official movie trailers through an elegant and responsive interface.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/cineverse.git
```

### Navigate to the project

```bash
cd cineverse
```

### Install dependencies

```bash
npm install
```

### Create a `.env` file in the project root

```env
VITE_TMDB_TOKEN=YOUR_TMDB_BEARER_TOKEN
```

You can obtain your TMDB Bearer Token from:

https://developer.themoviedb.org/

### Start the development server

```bash
npm run dev
```

The application will run at:

```text
http://localhost:5173
```
